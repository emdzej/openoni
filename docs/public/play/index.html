Oni in your browser

OpenOni runs here as openoni.wasm on the gasm runtime: the same module as on the desktop, a port of the original game's code, reading the levels, characters, sounds and scripts from your own copy of Oni. Nothing from the game is on this site, and nothing you pick leaves your computer.

This is a work in progress. Level 1 plays from the start of the training to the start of the warehouse mission, where the enemies fight back with fists and guns; the menus and saving are not there yet. See Status.

What you need

  • Oni for Windows (Bungie West, 2001; the program Oni.exe v1.0): the CD as an .iso image, its files copied off the disc, or an installed copy. See Game data.
  • A browser with WebAssembly, Web Workers, WebGL 2 and OffscreenCanvas: a recent Chrome, Edge, Firefox, or Safari 17 and later.
  • About 650 MB of browser storage to import the data (once; later visits start at once; a CD image takes its own size, about 420 MB), or none to play without importing.
  • A keyboard and a mouse.

An .iso image of the CD, or a folder with the CD's files (ONISETUP.EXE, ONISETUP.002, ...) or an installed game (Oni.exe and GameDataFolder). From the CD the game reads its files out of the installer's archive itself, with no install step.

    Importing copies the files the game reads into this site's private browser storage (OPFS). Playing without importing reads them from what you picked, which you'll need to pick again next time.

    Every level plays through to the end of the game. The original can't skip its intro; the box above leaves it out.

    Controls

    The original's default keys. Click the game to lock the mouse: it turns Konoko and aims. W A S D move, Caps Lock walks, Space jumps, Shift crouches, F or the left button punches, C or the right button kicks, Ctrl is the action key (consoles, doors), Q picks up, E drops, R reloads; with a gun, the left button fires. The arrow keys turn and aim too.

    Esc ends the game (there is no menu yet). In fullscreen the browser takes Esc to leave fullscreen first.
